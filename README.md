# Bookstore Data Extraction and Analysis

## Project Overview
This project focuses on web scraping and data analysis using [Books to Scrape](https://books.toscrape.com/), a practice website for learning web scraping. The goal is to extract book information, analyze pricing and ratings, and generate useful business insights.

## Tools and Technologies
- **Python** — Core programming language
- **Requests** — Fetching website data
- **BeautifulSoup** — Extracting information from HTML
- **Pandas** — Data cleaning and analysis
- **Matplotlib** — Data visualization

## Key Tasks
- Scraped book information from the website.
- Cleaned and organized the collected data.
- Analyzed book prices, ratings, and availability.
- Exported the dataset to a CSV file.
- Created visualizations and developed data-driven business recommendations.

## How to Run
1. Open the Jupyter Notebook in Google Colab.
2. Install the required Python libraries.
3. Run the notebook cells in sequence.
4. Review the analysis, visualizations, and generated CSV file.
